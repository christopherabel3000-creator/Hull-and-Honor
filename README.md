# Hull and Honor

A single-player space trading, piracy and pirate-hunting game, built to be played with a screen reader (VoiceOver on iPhone, JAWS or NVDA on a computer). Plain HTML and JavaScript, no build step.

Play it on GitHub Pages: https://christopherabel3000-creator.github.io/hull-and-honor/

You are a captain with one ship in a randomly generated galaxy of about 120 systems. Trade, run contracts, smuggle, raid Guild convoys or hunt pirates. The Merchant Guild, the Concord and four pirate clans all remember what you do, and your reputation opens stories, ships and ports, or closes them.

See DESIGN.md for the full design and how each stage was built.
